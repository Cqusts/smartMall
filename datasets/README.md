# datasets —— 数据集配置

只存**配置与元数据**，不存实际数据（实际数据在对象存储与 MySQL 的 ODS 层）。

## 冷启动的三条腿

| 来源 | 阶段 | 说明 |
|---|---|---|
| 公开学术数据集 | 冷启动主力 | JDDC / JDDC 2.0 / ECD，走正式授权申请 |
| LLM 合成 + 人工校验 | 冷启动补充 | 覆盖公开数据集没有的自有商品 |
| 自有系统真实对话回流 | 长期主力 | Trace → 数据中台 → 清洗 |

⚠️ **本项目不采用爬取路线**。爬取的客服对话涉及平台服务协议与第三方用户隐私，
且一旦进入训练集无法剥离。详见 [docs/15-risks-compliance.md](../docs/15-risks-compliance.md)。

授权范围登记在 `ds_source` 表，是合规审计的依据。
