# 演示商品图

来源：[Unsplash](https://unsplash.com)，Unsplash License（可免费商用、无需署名，
但这里仍然记录来源——演示数据的出处说不清，是作品集里最容易被追问的一点）。

尺寸统一 600×600 居中裁切、q=75，十张合计约 460KB。**存在仓库里而不是引
外链**：`test_page_has_no_external_dependencies` 要求整页零外部请求，
演示环境常常没有外网，"打不开"比"不好看"严重得多。

## 挑图的一条硬规则：不要带可辨认的品牌

第一批下下来的十张里有三张分别印着 ZARA、NIKE、KIIKII 的标，已经换掉。
把真品牌的商品照挂进一个虚构店铺、配上编出来的价格和库存，性质上是在
冒充别人的货——跟这个项目里"不许编造本店信息"是同一条线。

后续加图沿用这条：**看得清的商标一律不用**，哪怕是小众牌子。

## 文件名就是 product_id

`9001.jpg` 对应 `product.id = 9001`，数据库 `product.main_image` 存文件名，
前端拼 `/img/` 前缀。这样加商品只改数据不改代码。

落成 `knowledge_item(modality=image)`，用来补 eval 暴露的商品知识缺口。
